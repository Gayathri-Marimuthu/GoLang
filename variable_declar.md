| Item                 | Naming Convention          | Example                    |
| -------------------- | -------------------------- | -------------------------- |
| Variable             | `camelCase`                | `userName`, `totalPrice`   |
| Function             | `camelCase`, verb          | `getUser()`, `saveOrder()` |
| Method               | `camelCase`, verb          | `Update()`, `Print()`      |
| Struct               | `PascalCase`               | `Employee`                 |
| Interface            | Usually ends with `-er`    | `Reader`, `Writer`         |
| Package              | lowercase                  | `service`, `utils`         |
| File                 | lowercase with underscores | `user_service.go`          |
| Exported (public)    | Starts with uppercase      | `GetUser()`                |
| Unexported (private) | Starts with lowercase      | `getUser()`                |
